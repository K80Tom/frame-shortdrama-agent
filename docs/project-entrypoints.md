# 项目入口收敛（#181）

日期：2026-11-11；Owner：@K80Tom / @255308153；适用 `feat/project-entrypoints`，基于 `dev df976eb`。

## 实现范围

- 一级目的地：工作台、项目、资产库、AI 视频、设置。设置保持在侧栏底部；方法库、质量中心、3D 预演和指南合并进“更多/高级工具”，GitHub 原有外部操作也保留在该面板。命令面板不再平铺项目内部工具。
- 首页以真实最近项目为主体，只保留新建和继续两个主行动；移除重复的快捷工具、功能卡和参考图库。参考仍在资产库的“示例参考”中。空目录/来源失败不会再混入浏览器练习，单个目录失败不隐藏另一个已加载来源。
- 新建入口只有剧本与小说。剧本使用既有 POST /api/projects，成功后进入所创建项目概览，“添加剧本”指向同项目编辑器；项目模式隐藏再次新建和重复项目选择。小说进入真实导入入口，不提前伪造剧本项目。
- 旧 production/canvas/automation 全局入口改为真实项目选择；带项目 ID 的原有入口仍可用，automation/video 仍为独立视频。storyboard 和 script 本地练习保留，样例移至指南并明确不会用于正式制作。hash 前进/后退与未保存拦截不删除。

## 边界与回退

本 PR 只修改前端入口和已有页面组织，不修改后端 API、数据库、付费/预算提交或正式分镜机制。#182 的真实聚合概览/正式项目分镜、#183 的任务聚合/制作分层、#184 的人工编辑不可变候选仍未在此实现；整个 #180 不因此完成。

前端可独立回退，不迁移或删除业务数据，不取消或重建在途运行。浏览器验证使用模拟 HTTP，不是实际 PostgreSQL、多租户服务端鉴权、供应商或生产部署验收。改动超过 300 行，当前 head 必须由非作者真人审查，不自动合并。
