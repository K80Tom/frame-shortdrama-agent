# 历史记录索引

> 这是追溯入口，不是默认阅读目录。先搜索再读命中记录，不把历史结果当成当前证据。

## 按需使用

1. 先在本文件索引或 `history/` 的限定范围内搜索月份、主题、Issue 或决策编号。
2. 只读取命中的记录及其必要上下文，不连续读取整个目录。
3. 当前状态始终回读 [NOW.md](../NOW.md)；能力证据回读 [功能台账](../docs/feature-status.md)。

## 归档标准

仅归档有复用价值的设计背景、事故与恢复、关键验证、决策替代和重要迁移过程。每条记录应包含日期、适用范围或提交、问题、处理、实际证据和限制；使用项目内相对链接，不写入秘密或个人设备私有路径。

不归档完整聊天、日常安装拉取、无结论操作流水或重复状态快照。旧过程没有独立价值时，直接修订当前权威文档即可。
