# 红果短剧编剧 · 工业化剧本引擎 v4.0

> **本 skill 由两条来源合成**：
> ① **`short-drama-factory v3.2`**（MIT，见 `LICENSE`）提供工业化结构引擎——情绪契约单元链、篇幅三档、60/80/100 与 30/40/50 集结构、三级付费墙、跨集连续性台账、机检脚本。
> ② **红果短剧创作服务平台《短剧编剧第一课》01–10 期**（凉白开 / 白羊 / 刀锋 / 咪呜 / 骏乐 / 燕北六家工作室访谈）提供平台视角的创作标准——选题评估、黄金开场工具箱、主线孵化、节奏分区、期待/悬念/钩子、情绪点编排、可拍性与过稿、台词打磨、网文转型。
>
> **定位不变：只产出剧本层内容，不含分镜 / 资产 / 视频制作衔接。**

## 二、 篇幅三档（先定档再动笔）

| 档位 | 时长 | 正文体量（实拍 / 漫剧） | 场景 | 单集拍数 | 全剧集数档 | 机检 |
|---|---|---|---|---|---|---|
| **标准档**（默认） | 90～120 秒 | 350～500 / 260～400 | ≤2 | 1 拍 | 60 / 80 / 100 | `--format standard` |
| **长档** | 165～195 秒（约 3 分钟） | 650～850 / 520～680 | ≤3 | 2 拍 + 中段小钩 | 30 / 40 / 50 | `--format long` |
| **漫剧档** | 60～90 秒 | 260～400 | ≤2 | 1 拍 | 60 / 80 / 100 | `--format manju` |

未指定档位默认标准档；用户说「长档 / 3 分钟 / 一集三分钟」即切长档；用户说「漫剧 / AI 漫剧 / 竖屏动画」即切漫剧档。**档位一旦定下，全剧不混用。** 规格权威：`references/hongguo-beat-sheet.md` §三、§四。

## 三、 唯一执行顺序

```text
任务理解
  → 选题评估(课02)          ← 五问 + 四条准则，判不过就换题
  → 流派判定                 ← 情绪流 ⇄ 剧情流（判错全白写）
  → 档位判定                 ← 标准 / 长档 / 漫剧
  → 赛道锚定                 ← genre-map 12+ 赛道
  → 一句话故事 + 人物圣经(课04)
  → 全剧结构（四幕 + 单元链 + 回合表 + 付费墙）
  → 分集规划（入台账）
  → 单集撰写（黄金三角 + 开场 + 钩子 + 情绪点）
  → 医生精修（台词七维）
  → 可拍性与合规（课08）
  → 机检（单集 + 台账）
```

冲突裁决顺序：**当前用户明确要求 > 本文件 > 对应权威 reference > 其他。**

### 三道门（按序，任一门不过就停）

1. **选题门（课 02 新增）**——五问：目标用户是谁？核心情绪共鸣点是否明确？视觉化落地难度高不高？有没有踩政策红线？有没有市场数据支撑？五问任一个答不上，先改题再动笔。
2. **流派门**——读 `emotion-flow-roundtrip.md` §一。判断问句：「能不能用一句话说清观众追的是哪种情绪？」能→情绪流；「观众追的是'接下来发生什么'还是'他什么时候信/认/跪'？」后者→情绪流。
3. **档位门**——见 §二。定错档位则全剧体量错配。

## 六、 绝对红线（12 条）

前 9 条来自工厂引擎，后 3 条为课程新增。

1. 严禁开篇铺垫：前 3 秒必须见血、见冲突、见危机。
2. 严禁台词讲设定：背景走物证/反差/侧写/反转。
3. 单集正文体量按档锁死（见 §二），场景数按档锁死。
4. 每集必有断章卡点；严禁平静收尾。
5. 严禁全员播音腔：反派要市井刻薄，主角要隐忍冷酷/爆发霸道。
6. 情绪流项目：情绪契约贯穿全剧，但单一矛盾单元严禁烧过 30 集（长档折半为 10～15 集）。
7. 每回合反驳/反击必须带新增量（新信息/新行动/新代价），复读前一回合话术即废稿。
8. 合规一票否决类不碰；暴力用「受力震飞/骨裂/倒地」写意替代直观血腥。
9. 长档单集必设中段小钩（≈90 秒），且回合 B 必须双升级。
10. **严禁「上帝视角」写作**：不能依赖剧本之外的小传/设定让观众脑补，关键信息必须从正文第一行起通过情节、对白或行为传递。
11. **严禁把 OS/心理描写当台词念**：能通过对白表达的绝不用画外音，能用表演呈现的内心活动绝不用独白；少写「心理」，多写「行为」。
12. **严禁脱离制作现实**：写之前先算经济账——新场景、夜戏、外景、大群演、水下/高空/爆破都在加钱加风险；非主线关键节点的此类内容直接删简。

## 七、 出稿前双自检

**机检（硬门，FAIL 必须修复后重跑，不得裸交）**

```bash
python3 scripts/validate_episode.py <单集剧本文件> [--format auto|standard|long|manju] [--prev 前集.md ...]
python3 scripts/validate_series.py <台账文件> [--episodes 30|40|50|60|80|100]
python3 scripts/validate_episode.py --self-test
```

机检覆盖：体量 / 单句句长 / 场景数 / 前 3 秒冲突 / 开篇禁词 / 断章卡点 / 中段小钩 / 复读 / 情绪流变词 / 合规红线词 / **黄金三角（身份+困境+目标）** / **上帝视角与心理描写**。

**人工自检（课程清单，逐条过）**

- [ ] 前 3 秒见冲突，前 30 秒讲清「我是谁、我在哪、我要做什么」（黄金三角）。
- [ ] 本集有 1 个让观众觉得「有意思」的小情绪点；大情绪点落在 5～10 集的间距上。
- [ ] 主角目标足够具体（「三个月内赚到一千万」优于「我要成为有钱人」），且只有一个核心目标。
- [ ] 本集结尾的「未完成感」是情节自然推到的临界点，不是为了勾人硬加的。
- [ ] 没有为制造悬念而牺牲基本逻辑；反转做到「意料之外，情理之中」。
- [ ] 困境情节没拖过久，且留了反击希望与明确的对立动机。
- [ ] 每个有名字的角色都能回答「他为什么必须存在」。
- [ ] 每句台词读出来不拗口；砍掉三分之一后核心信息仍在。
- [ ] 场景能集中拍、演员好调度、审核过得去。
- [ ] 打脸对象是推动剧情的主要反派，没有靠践踏弱者制造情绪。
