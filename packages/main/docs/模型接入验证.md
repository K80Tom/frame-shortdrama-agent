## 2026-10-30：剧本拆解失败的离线修复（未复测）

对上节失败的跟进，全部为离线代码修改，**没有发起任何真实模型调用或计费请求**：

- `STAGE_OUTPUT_INVALID` 不再只返回一句笼统结论。结构校验失败时，错误消息附带脱敏的字段级诊断：JSON 路径（如 `dialogues[0].source`）加中文原因（缺少必需字段、类型不符、出现未约定字段、长度/条目越界等），最多列出 5 处，路径与字段名均截断限长。诊断只包含结构与约束，不复制模型生成的文本值。
- 说话人与证据不一致从笼统协议错误拆分为独立错误码：`SPEAKER_EVIDENCE_MISSING`（指定了实体但没有证据）与 `SPEAKER_EVIDENCE_ORPHANED`（未指定实体却给出证据），消息附带对应对白 tempId，便于定位到具体输出条目。
- 剧本拆解的 `MaasStageModelAdapter` 与小说链路对齐，显式发送 `thinking: { type: 'disabled' }`。此前一次实测中上游推理占用 3866/5876 输出 tokens，小说链路关闭思考后三章全部通过。该参数仅对 maas 连接生效，其他 provider 的请求体不受影响。
- 校验门槛、提示词版本（`extract-facts-prompt/1`）与输出契约未改动；历史 Run、Attempt 与错误记录不改写。

离线验证：后端 `npm test`（含构建）395/395 通过，其中新增 3 项测试覆盖字段级诊断、超长内容截断脱敏与两个新错误码，并断言适配器请求体携带 `thinking`。仍未执行付费复测：下次对《赴约》练习的真实调用需用户单独授权，届时字段诊断可直接指明不合法位置；复测通过前，"事实拆解尚未跑通"的结论保持不变。
