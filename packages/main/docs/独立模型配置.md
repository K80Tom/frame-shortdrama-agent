# 独立模型配置

更新：2026-10-23。现为「连接库＋用途选择」：可同时保存多套完整连接，切换模型不覆盖旧连接。文本按用途路由；生图已接入小说缺失资产的结构化视觉简报、单张候选生成、人工接受/拒绝和生成溯源，只有接受后才建立正式关联；Seedance 生视频已接入提交/查询客户端，尚未进入镜头生产页。

## 页面与用途

打开 `http://127.0.0.1:5173/#/settings`，点击「管理模型连接」，进入 `#/settings/models`。

| 配置 | 当前消费者 | 状态 |
| --- | --- | --- |
| 拆解 `breakdown` | 小说单轮提取、多阶段逐段查漏／修复／复核，剧本事实拆解 | 已接独立文本路由 |
| 生图 `image` | 小说待补人物、场景、道具 | 已接 `AssetVisualBrief`、逐次单图候选、人工接受/拒绝、接受后版本关联与未知结果防重试 |
| 生视频 `video` | Seedance 异步任务客户端 | 已接提交与查询协议；镜头任务持久化、UI 和成果入库待接 |
| 通用 `general` | 通用 `/api/model-calls`、已有分镜设计流程 | 已接独立文本路由 |

每个已保存连接（profile）独立包含名称、类型（text/image/video）、完整 HTTPS 接口、准确模型 ID、`Authorization: Bearer` 或 `api-key` 鉴权、密钥、超时。四种用途只选择连接 ID；同一文本连接可同时用于拆解和通用，也可各用不同连接。最多保存 64 个连接，不自动删除未选中的模型。

文本连接有输出 Token 上限，实际请求不超过配置与单次请求两者的较小值。支持模型 ID 中的空格，不擅自把网关别名改成官方 ID。不支持任意自定义请求头、签名、多模态输入或任意供应商协议。

操作：在「已保存模型」添加／编辑／复制完整连接 → 在上方选择用途及模型 → 点击「应用到此用途」。只改下拉框不会保存，未保存选择跨用途切换保留；刷新、离开或重新读取前有提醒。「不分配模型」明确停用该用途，不会回退旧模型。

文本接口必须包含 `/chat/completions`，不要填写网站首页或仅 Base URL；不接受 URL 中的用户名、密码、查询参数、片段或非 HTTPS。当前仍是非流式 `stream:false`，不能把供应商给出的流式 curl 示例当作项目已验证流式接入。

## 保存、迁移和密钥

- 主服务写入项目内被 Git 忽略的 `outputs/private/model-connections.json`，新目录权限 `0700`、文件 `0600`，临时文件同步后原子替换。文件含明文密钥，不是加密保险库；本机同账户进程或管理员仍可能读取，备份需按敏感文件处理。
- 文件为 `schemaVersion:2`，保存 `profiles[]` 与四用途 `assignments:{role:{profileId,revision}}`。v1 四用途文件启动时迁移，保留原地址、模型、密钥、限制、清空状态与选择版本；相同完整连接可合并为一个 profile，原用途选择不变。损坏／无法读取则启动失败，不静默覆盖或回退。无需数据库迁移。
- 仅没有配置文件时，从 `.env` 的 `LLM_*` 初始化文本连接与两个文本用途；媒体不继承。已有文件优先，不自动导入环境模型或恢复清空密钥。「导入旧环境连接」是显式操作、可重复执行；已有相同地址／模型／鉴权的连接不会覆盖，也不会补回已清除密钥，不改变用途选择。
- 页面只收到 `hasApiKey`，永不收到密钥原文。编辑时密钥框留空保留，填写则替换；勾选「清除此连接的密钥」并保存才会清除这份连接。共享该连接的用途都会变成不可调用；其他独立 profile 不受影响。保存成功关闭编辑并清空输入状态，不写入浏览器存储。
- 「复制连接」可显式复用原连接已保存密钥，浏览器只传原 ID／版本，不取回密钥。复用必须保持相同接口与鉴权方式；换接口需单独填密钥。源连接版本变化则拒绝旧基准复制。复制后两个 profile 各自独立，不联动更新或清除。
- 未保存更改跨用途切换保留在页面内存；离开／刷新有提醒。重新读取前确认丢弃草稿。并发保存比较期望版本，冲突返回 409，不覆盖其他页面修改。
- 新任务立即生效，无需重启；运行中的小说多阶段、剧本执行和分镜调用固定启动时快照，不中途换地址或凭据。全部角色和快照共用进程模型并发额度。
- 编辑共享 profile 会更新所有引用它的用途版本，页面会列出影响范围；未选中的连接编辑不影响其他用途。用途选择与 profile 编辑分别做版本比较，其他页面已修改则返回 409，不覆盖。已分配的连接不能直接改类型；先取消对应用途分配。
- 剧本 Run 保存不含密钥的连接版本；拆解连接修改后旧 Run 不可继续执行，需新建，历史结果仍可校对。小说显式继续旧检查点会按新请求启动时配置执行后续阶段，原尝试账本保留旧模型名。
- 正常小说提取和分镜生成请求带显示时的 `expectedModelConnectionRevision`。其他标签页已换模型时，后端在登记尝试、发送原文或付费调用前返回 `MODEL_SELECTION_CHANGED`，要求刷新并重新确认，不悄悄使用更晚选择。老 API 客户端不带此可选字段时保持兼容。
- 密钥与私有网关地址不写入文档、示例或版本库。出现在不应共享记录中的凭据应在服务商处撤销并更换。

## API

- `GET /api/model-profiles`：连接库、四个用途当前选择、旧环境导入可用标记；无密钥原文，`Cache-Control: no-store`。旧 `GET /api/model-connections` 返回同一安全视图。
- `POST /api/model-profiles`：添加独立连接；可带 `copyCredentialsFrom:{profileId,revision}` 在同接口／鉴权下显式复制密钥。
- `POST /api/model-profiles/:id`：编辑连接，必须带 profile 的 `expectedRevision`。
- `POST /api/model-profiles/import-environment`：空对象请求，显式导入旧环境文本连接，不改变选择、不覆盖已有密钥。
- `POST /api/model-assignments/:role`：`{profileId,expectedRevision}`，期望版本取该用途；profileId 为 null 表示停用。文本、生图、生视频类型严格匹配。
- 旧 `POST /api/model-connections/:role` 保留兼容：只编辑该用途，共享 profile 时先分离，避免旧客户端修改一个用途却影响另一个。
- `GET /api/models?role=breakdown|general`：对应用途的文本模型目录，默认通用；媒体不可进入文本通道。
- `POST /api/model-calls`：通用模型，仍需 `allowPaid:true`。传入模型名与通用配置不一致则拒绝，不跨配置选模型。
- `GET /api/asset-generation/status`：只检查当前生图连接字段，不调用上游；返回模型名与选择版本。
- `POST /api/novel-revisions/:id/asset-generation`：对已确认、待补条目显式授权生成 1 张候选图，必须带新的稳定 `intentId`、小说版本与生图选择版本；同一条目可通过新的授权逐张生成多个候选。
- `POST /api/asset-generation/:id/decision`：提交 `{decision:"accept"|"reject", expectedRevisionId, note?}`；接受后才正式关联，拒绝保留候选与溯源。旧 `/api/desktop-assets/:id/decision` 路径兼容。
- `SeedanceVideoClient`：内部客户端接口支持提交任务和按 task ID 查询；当前不暴露为网页生产接口。

添加连接示例（占位）：

```json
{
  "name": "我的文本模型",
  "kind": "text",
  "endpoint": "https://api.example.com/v1/chat/completions",
  "model": "your-model-id",
  "authType": "bearer",
  "apiKey": "",
  "clearApiKey": false,
  "maxOutputTokens": 8192,
  "timeoutMs": 180000
}
```

上述写接口仍要求本机 Host、受限浏览器来源和 `X-Shortdrama-Call: 1`。选择请求只传连接 ID 和版本，不传凭据；创建、编辑、导入的响应同时返回完整安全目录，失败不会覆盖已保存状态。

保存／读取不访问上游，不消耗额度；「配置完整」只代表字段齐全，不代表连接测试成功。不隐式探测、自动重试、跨用途回退或推断能力。每个图片候选都需单独额度授权；生成成功进入 `awaitingReview`，不会自动接受或建立章节引用。人工接受也不代表自动视觉质检。自定义模型只声明文本适配，不声称已验证窗口、图片能力或推理档位。API-key 适配保留旧 MAAS 行为；Bearer 通道不发送 MAAS 特有 `thinking` 参数。多阶段流程显式请求 JSON 输出，供应商不支持时停止，不自动去掉参数重试。生图候选不改编剧本，也不接分镜或 3D。
