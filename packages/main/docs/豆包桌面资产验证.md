# 豆包桌面资产回传验证

> 历史验证说明：本页保留 2026-10-23 早期桌面可行性证据。当前运行方案已经改为服务端豆包 API，不再控制桌面客户端；请以[豆包 API 一键资产](豆包桌面一键资产.md)为准。

验证日期：2026-10-23。

## 结论

已通过桌面自动操作已安装的 **DoubaoWork.app（豆包工作）**，使用当前登录账号的 Seedream 5.0 Pro 生成一张图片，再通过本项目正常资产页面上传、保存并关联到小说已确认的道具条目。未开通额外模型 API，未配置或调用生图 API，未购买套餐，也未改动 3D 导演台。

这是一次由开发助手执行的桌面端到端可行性验证，**不是本项目已具备无人值守或一键桌面生成服务**。Seedance 2.5 在客户端技能列表中可见，本次未提交视频生成，不能据此宣称视频链路或视频额度已经验证。

## 实际链路与证据

1. 读取常用库《吞噬星空》前三章校对样本中第一章的已确认道具「书籍」，其原先资产状态为待补。
2. 在豆包工作客户端的新任务中选择 Seedream 5.0 Pro，仅请求一张道具图。明确区分原文事实和本次视觉设计，并要求使用现有额度、不购买其他服务、不重复生成。
3. 客户端完成任务并将图片保存至项目的 `outputs/doubao-desktop-acceptance/book.png`。界面显示总用时 2 分 16 秒、消耗 **17.42 点**；该数字是这次工作任务的界面总用量，不是单独推算的图片模型价格。
4. 在正常网页「资产 → 新建资产 → 上传本地图片」导入真实文件，命名为「【桌面验收·非正式定稿】书籍 · Seedream 5.0 Pro」，并保留来源与设计边界说明。

## 本次实现的导入能力

- 新增 `010_local_asset_media.sql`，已在常用本地数据库执行并重启后端。
- `POST /api/assets/import` 接受类型、名称、说明和 Base64 图片，图片字节、MIME、哈希与资产登记同事务保存。
- `GET /api/assets/:id/content` 读取原图；`?download=1` 下载。浏览器不需要访问豆包内部链接，也不依赖临时生成 URL。
- 支持 PNG、JPEG、静态 WebP；最多 6 MiB、最长边 8192 像素、总像素 3200 万。容器校验不等于完整解码、视觉质检或正式采用。
- 相同字节和元信息的重复导入返回同一记录，不覆盖既有素材；已有 HTTPS 登记保持兼容。

验证：后端 173 项测试、前端 54 项测试及两端构建通过；导入专用测试独立复核 6/6 通过。新增数据库集成测试用例尚未单独运行，本次真实常用库迁移、导入、原图读回及版本关联提供了实机验收证据；没有把未运行用例标为通过。
