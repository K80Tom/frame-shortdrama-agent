## 取材与整理方式

- 从原页面提取“布景”两段，以及从“李妈（从左边门出来）午饭摆好了。”到落幕的连续结尾。
- 新增标题、作者信息和【原剧布景】【结尾节选】两个编辑标记；它们不是原剧对白。
- 保留页面简体显示下的原有措辞、代词与括号动作，没有现代化改写或补写剧情。“莎法榻”“狠”等旧写法有意保留。
- 省略开头、中段、序和跋。结尾存在上文关系，不能根据这个短片段虚构完整前情。
- 原页面将作品标注为公有领域，说明其在美国及中国大陆等地区的状态；本地保留作者和出处，不将本次整理标为原创剧本。

## 为什么用它起步

它是早期独幕话剧节选，不是现代商业微短剧的完整一集。作为第一个小输入，它有明确对白与动作，适合检查拆解流程；不能单凭它验收多场景能力或现代短剧风格。

建议首先观察这些行为，而不把下面的说明交给 Agent 当作剧本文本：

1. 能否把“田女”“田女士”“亚梅”识别为同一人物，而不拆成三个角色。
2. 能否区分片段中实际出场的人和只在对白、信中被提及的人。
3. 能否提取信、字条、花瓶、大衣等与动作有关的道具，并保留依据。
4. 能否处理括号里的动作、场外声音、读信和重念，而不遗漏对白。
5. 能否识别“怕是回学堂去了”是角色的猜测，而不是已经发生的事实。
6. 能否将景别、运镜、预计时长等新增内容标记为设计建议。
