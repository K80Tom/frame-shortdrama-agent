# 《终身大事》结尾节选：参考拆解草稿

**用途：先看清 Agent 应该交付什么。** 本文由开发助手根据输入整理，尚未经用户审阅；没有运行项目 Agent。梗概与清单需要忠于输入，镜头方案允许有多个合理答案。

## 输入与阅读方式

[原剧本 TXT](终身大事-结尾节选.txt) · [完整 JSON](终身大事-参考拆解.json) · [分镜 CSV](终身大事-参考分镜.csv)

输入共有 21 行。本文的 L5、L16 等指原 TXT 的物理行号，空行也计数。标题、作者及编辑标记不是剧情。JSON 额外保存行内位置与逐字引文，并记录原文 SHA-256，后续原文有修改时应重新绑定引用。

本文把三种内容分开：**原文依据**（对白、动作、布景）、**依据上下文整理的结果**（人物别名合并、梗概、午饭时段）、**设计建议**（镜头数量、景别、运镜、预计时长）。角色说的话是原文事实；话中描述的事件不一定已经在画面里发生。

## 1. 梗概

午饭时，田先生与田太太劝女儿去吃饭，女儿拒绝。父母进入饭厅后，亚梅收到李妈递来的陈先生的信，读信并重申应该自己决断。她让李妈转告父母先吃饭，随后穿上大衣、写下字条、压在花瓶底下并离开。父母出来寻找，田先生读到字条称亚梅已乘陈先生的汽车离去；田太太坐倒在靠椅上，田先生冲到门边后回望，显出迟疑。

依据：L9—L21。节选未交代前面的具体争执，不补写完整前情或陈先生与亚梅的关系称谓。

## 7. 哪些内容不能当作已发生的画面

| 原文内容 | 参考结果的处理 |
| --- | --- |
| “陈先生还在汽车里”等是问答中的信息，“坐了陈先生的汽车去了”是字条自述。 | 记录人物所说内容，不补成镜头中已经发生的上车、驶离。 |
| “怕是回学堂去了”是母亲猜测；“他生了气了”是父亲解释。 | 保留对白，不设学堂场景或额外发怒事件。 |
| “不要哭了”是母亲的话。 | 不能只凭这句话新增具体哭泣表演；参考镜头不补写。 |

田太太最后是后仰、坐倒；田先生是冲到门边后回头迟疑。不能擅自改为母亲昏倒、父亲追出去。

## 9. 用它怎样检查第一版 Agent

- **必须保真**：四位出场人物与一位提及人物区分正确；别名合并；来信与字条区分；写字台与圆桌区分；对白和关键动作有原文依据。
- **不得编造剧情**：不增汽车外景、回学堂情节、确切季节或未经原文支持的人物设定。
- **镜头可有不同答案**：不用强求生成恰好 24 镜头；检查是否每行连续、顺序合理、没有漏掉关键事件，设计与事实明确分开。
- **导出一致**：JSON 保存完整内容，CSV 是同一份分镜的视图；两个文件的镜头 ID、顺序、对白和设计保持一致。
- **本样例覆盖不到**：多场次重做、人工修改保护、长文本与现代短剧节奏，需要后续专门样例验证。
