# 短剧制作流程可视化

独立的本地教学页面，参考 LibTV 的深色侧栏、圆角卡片和创作工作区样式。无旧公司服务依赖。

打开页面后可以逐步查看剧本、拆解、文字分镜、外观参考、可选白模预演、镜头画面、视频、声音剪辑、检查导出的输入与产出。白模可以切换全景、双人同框、人物近景，并调整机位角度。

运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory dist
```

在本机浏览器打开 http://127.0.0.1:8765/ 。停止服务后该地址不再可用；重新运行即可。

- `dist/index.html`、`style.css`、`app.js`：页面与演示内容。
- `dist/white-preview.js`：本地三维站位/机位示意，无外部模型调用。
- `dist/vendor/`：Three.js 0.180.0 及 MIT 许可，使用本地副本。
- `dist/assets/duel.png`：AI 生成原创造型示意图。页面中的其他取景展示是这张图的裁切，不冒充独立生成的分镜图。

示例是《斗破苍穹》背景的助手重写练习，不是小说原文或官方剧本。页面用于说明制作流程，尚未接通剧本 Agent、图片/视频生成、音频或剪辑服务，不会发起付费任务。所有交互均在本机完成。

此页面是用户单独要求的流程教学页，不代表已经实现项目第一版的剧本拆解内核。本次按此前确认的本地网页形式交付，未公开发布。
