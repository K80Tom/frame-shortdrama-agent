# 旧平台精选参考（只读）

本目录保存旧「中文短剧平台」三件套（`短剧Main` / `shortdrama-agent` / `shortdrama-cli`）中**对新项目仍有参考价值的少量原文**，用于设计对照与规则提炼。

- 这里**不是可运行代码**，不参与构建、测试或部署；旧平台的完整可运行工程已从仓库移除，需要时可从历史提交找回。
- 现行产品的唯一实现位于 [`../shortdrama-agent-lab`](../shortdrama-agent-lab)。引用这里的规则时，应在 lab 内用本地等价物重新实现，不要恢复旧平台的数据库、对象存储、密钥或部署体系。

## 目录

| 目录 | 内容 | 主要用途 |

| `contracts/` | 旧 Main v0.2.0 冻结合同七篇 | 五层提示词草稿、单分镜生产意图、白名单内资产重排、剧本 IR 导入、审核交付门禁、粗剪映射、Seedance 资产登记、声音工坊 |

| `research/` | 早期源码分析与 MVP 建议调研 | 历史背景 |
