## 〇、产品模型(DC 原话要义,勿漂移)

粗剪素材工作台的分工:**左侧=已匹配的素材原材料**;工作台的实体/风格/媒介
参考栏=用左侧已匹配资产**制作参考控制包**;图片/视频/音频/3D 导演台页签=
**生产参考控制包内容的车间**;都准备好、人工确认后,才生成粗剪素材。
生成的依据是功能,功能尊重视频 API 文档支持的能力,不发明。

## 一、提交模式映射(互斥铁律)

API 三场景互斥不可混用(官方文档明示):

| 平台意图 | API 场景 | content 形状 |
| --- | --- | --- |
| **默认主路:参考控制包生成**(0.2.0 拍板 reference 为主模式) | 多模态参考生视频 | 图 1-9 张 role=reference_image;视频 0-3 个 role=reference_video(总时长≤15s);音频 0-3 段 role=reference_audio(≤15s,不可只有音频);文本=编译提示词 |
| 锚帧(用户**显式**选择的高级项) | 图生视频-首帧 / 首尾帧 | 1 图 role=first_frame,或 2 图 first_frame+last_frame(role 必填) |
| 纯文本快速通道(永久合法) | 文生视频 | 仅文本 |

**校验规则(服务端强制)**:
1. 提交 payload 只能属于一种场景;参考集非空时**默认多模态参考**,任何资产
   不得被隐式指派为 first_frame——**违约实例:DC 的道具参考图被静默当首帧,
   本合同起为 P0 缺陷**;
2. 用户显式选锚帧时,锚帧组与 reference_* 组互斥,UI 与服务端双侧拦截并
   说明(如需"参考+指定首帧"效果,走多模态参考+提示词指定,文档明示
   此间接路径;严格首尾一致才用首尾帧模式);
3. 提交前 UI 必须展示将采用的模式与清单("多模态参考:图 3/视频 1/音频 0")
   ——透明是确认卡的一部分。

## 二、两段式提示词编译(context engineering)

提示词=**固定自动填充段+人工补充段**,拼接后提交:

- **自动段(服务端编译,只读可见)**:从结构化真源编译——剧集/场次背景、
  出场角色描述、场景描述、镜头意图、参考控制包内各资产的登记描述(按栏
  组织),生成论文级详细提示词;编译模板/顺序/负面词表在服务端(R7),
  版本化;中文≤500 字预算内做裁剪优先级(文档:字数过多致信息分散);
- **人工段(可编辑)**:补充需求与临场信息,默认空;
- 前端呈现:自动段折叠展示可展开审阅,不可直接改(要改去改真源=资产
  描述/场次信息,改完重编译);人工段独立输入框;
- 对话台词包双引号(文档:优化 generate_audio 音频效果)。
- **R144 服务端默认层(v2)**：`scene_id` 存在的视频段落生成固定加入
  「只使用音效，不使用背景音乐(BGM)」约束；方括号时间码、行首时间码和镜号后的时间码
  在估价前剥离，时间轴只留在 UI。自然语言里的具体时间（如「晚上 20:30 集合」）保留。
  该结果随报价的 `prompt_compilation` 快照固化，estimate 与 submit 不能漂移。

## 三、API 参数事实表(2.0 系列,实现与计费必须尊重)

| 参数 | 事实 | 平台口径 |
| --- | --- | --- |
| generate_audio | **默认 true(有声)** | 显式传值;UI 给开关;计费口径按有声/无声分别实测入价格档 |
| duration | [4,15] 或 -1 智能 | 走能力档;-1 时计费以查询接口返回 duration 结算,谨慎放开 |
| resolution/ratio | 480p-4k;adaptive 规则见文档 | 走能力档;4k=10bit/H.265 注意兼容标注 |
| seed/camera_fixed/frames/draft | 2.0 **不支持**(draft 仅 1.5 Pro) | 请求体不得携带(1.0/1.5 由各自能力档决定) |
| service_tier | 2.0 仅在线 | 不传 |
| callback_url | 任务状态推送(queued/running/succeeded/failed/expired) | 0.2.x 用轮询,**callback 列为后端优化项**(替代轮询,S16 条 2 数据源升级路径) |
| return_last_frame | 尾帧回传,连续视频串接 | 1.0.0 M1 分段编排的既定机制,合同先记 |
| priority 0-9 | 同 Endpoint 队列插队 | 1.0.0 M1 生成队列优先级的实现机制 |
| execution_expires_after | 默认 48h,[1,72]h | 平台任务超时对齐设置,过期=expired 不计费口径待实测 |
| 真人人脸 | 2.0 拒收未授权真人素材 | 资产注册链(READY_FOR_DEV_SMOKE)就是解锁通道,已在途 |
| 参考图约束 | 宽高比[0.4,2.5]/边[300,6000]px/≤30MB | 服务端提交前预检,人话报错 |

## 四、实施切分

- **后端(k3 包 2,升为最高优)**:①提交映射修复(默认多模态参考+互斥
  校验+隐式首帧根除);②提示词编译器 v1(自动段编译+人工段拼接,模板
  服务端);③generate_audio/duration 等参数按本合同透传;④参考物预检。
- **前端(S16 已含条目状态;S17 接)**:模式透明化展示+两段式提示词 UI
  (自动段只读折叠+人工段输入);锚帧移入高级选项且与参考集互斥交互。
- 能力档:2.0 各档参数集按第三节修订登记(不支持的参数从档位剔除)。
