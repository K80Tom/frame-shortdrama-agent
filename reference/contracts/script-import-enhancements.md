# 剧本导入增强合同(v0.2.x,#24,2026-07-23 起草)

背景:丽芬 0.1.2 测试判决条 32-5(收,重要):用户真实上传《霸道狼王…》
.docx 被拒,导入门槛真痛。Sol 下包「剧本导入增强」以本合同为准。上位:
platform-ontology.md;既有真源:docs/contracts/v0.1.1/structured-script-ir.md
(结构化剧本=真源不变,本合同只扩入口与导入语义)。

## 一、docx/txt 导入(0.2.x 先行)

- 入口与 Excel 导入并列:「导入剧本」接受 .docx/.txt(.docx 用现成解析器
  提正文,不做版式还原);
- 解析=**AI 拆书解析+预览确认**:LLM 走 #28 网关(purpose=script-parse,
  逐笔 ai_calls)把散文体剧本切成 集→(场景?)→分镜/台词 的结构化预览;
  **预览确认前零落库**(确认卡红线同源);解析失败如实报错给手动分集
  兜底,禁 mock;
- 与拆书定妆同链:导入确认后的结构化剧本即拆书 agent(#27)的输入。

## 二、重复导入语义(必须显式定义,不静默覆盖)

按集对齐合并预览:导入文件与现有集对齐后,**已存在集逐集三选**:
跳过 / 覆盖(旧内容进版本历史,可回退)/ 存新版本(并存);新集直接
新增。预览页明示每集的对齐判定与所选动作,确认后一次执行。

## 三、每集内容可编辑(核对现状补缺)

集详情的剧本内容可编辑(标题/正文/场景归属),编辑走版本序列(本体
二-5),被分镜引用的集改动提示重检(R8 引用追踪)。按场景制作维持现状:
scene 可空已兼容,集必须(短剧按集交付),不改模型。

## 四、0.3.x 演进附注(不在本包)

Narrative Canvas 对象模型(台账条 11)作为剧本工坊/IR 演进参照:
Story/Frame/Events/Characters/Variables——把大纲从线性文本变成可验证
状态机(查断链/分支爆炸/出场依赖)。落 structured-script-ir 修订时吸收;
互动短剧(分支剧)远景不排。

## 五、验收

1. 真栈:上传真实 .docx(丽芬用例)→预览结构正确→确认落库→集/分镜
   可见;同文件重复导入→逐集三选生效,覆盖可回退;
2. ai_calls 有 script-parse 记录;预览确认前 DB 零写入;
3. 回收站语义:导入产生的集删除走回收站(30 天 TTL)。
